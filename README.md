# Andres Marte - Portfolio Website

A modern, responsive portfolio website showcasing my work as a full-stack developer, UX/UI designer, and photographer. Built with React, TypeScript, Tailwind CSS, and Framer Motion, featuring real projects, professional experience, and comprehensive skill demonstrations.

## 🌟 Features

- **Modern Design**: Clean, professional design with smooth scroll-triggered animations
- **Fully Responsive**: Optimized for all devices - desktop, tablet, and mobile
- **Featured Projects Grid**: Modern card-based layout with icon representations and gradient headers
- **Real Profile Image**: Professional photo display with elegant gradient frame design
- **Interactive Animations**: Powered by Framer Motion for smooth, engaging user experience
- **Contact Form**: Functional form with validation and success/error states
- **Comprehensive Resume**: Real professional experience from Framebridge, New Castle Metal, and freelance work
- **SEO Optimized**: Meta tags and structured data for better search visibility
- **Fast Performance**: Optimized for speed with 95+ Lighthouse scores

## 🚀 Technologies Used

- **React 18** - Modern React with hooks and functional components
- **TypeScript** - Type-safe development for better code quality
- **Tailwind CSS** - Utility-first CSS framework for rapid styling
- **Framer Motion** - Smooth animations and transitions
- **Lucide React** - Beautiful, customizable icons
- **React Intersection Observer** - Scroll-triggered animations
- **GitHub Pages** - Free hosting and deployment
